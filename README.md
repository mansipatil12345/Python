## ⚙️ Setup

Clone the repository:

```bash
git clone https://github.com/mansipatil12345/Python.git
```

Move into the project directory:

```bash
cd Python
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows:

```bash
.venv\Scripts\activate
```

Install dependencies if a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

## ▶️ Running Python Programs

Run a Python file using:

```bash
python filename.py
```

## 📊 Excel Export

Some projects use the `openpyxl` library to create and export data to Excel `.xlsx` files.

Install it using:

```bash
pip install openpyxl
```
